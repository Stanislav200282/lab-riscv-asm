## Вариант задания №2

Вариант задания 

Найти индекс максимального элемента массива. (N = 4, M = 3). 

## Результаты работы

* **lab1.S** - программа на RISC-V ASM
* **lab1.c** - программа на Си
* **lab1.elf** - компилированный Си файл
* **lab1.damp** - дамп-файл компилированного Си файла

Изначально максимальное значение задаётся равным 0 
Индекс максимального массива задаётся 0 0 (счёт индекса ведётся с 0)
С помощью передвижения поинтера перебираются все значения массива и сравниваются с максимальным значением, если значение из массива больше, то оно записывается в максимальное. 
В этом случае индексы обновляются на текущий.
